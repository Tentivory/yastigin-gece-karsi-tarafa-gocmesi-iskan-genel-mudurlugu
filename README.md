# T.C. İskân Genel Müdürlüğü
## Yastığın Gece Karşı Tarafa Göçmesi Daire Başkanlığı

**Resmî uyarı:** Bu depo bir şaka değildir. En azından mühür öyle söylüyor. Yastık, yorgan ve insan vücudu arasındaki her milimetrelik kayma **iskan ve yerleşim** kapsamındadır.

Gece 03:17'de yastığınızın yatağın öteki ucunda uyanması tesadüf değildir. Bu, planlı bir göçtür. Müdürlük bu göçü tescil eder, tapu verir, itirazı reddeder.

## Ne yapar?

`yastik.py` çalıştığında:

1. Yastık konumunu ölçer (hayali, ama ciddi).
2. Kayma yönünü belirler (kuzey-doğu yastık kuşağı).
3. Hak sahipliği belgesi basar.
4. İtiraz hakkınızı 14 gün içinde yorganın altına yazmanızı ister. Yorganın altına yazılan hiçbir şey okunmaz.

## Kuruluş

```bash
python3 yastik.py
```

İsteğe bağlı argümanlar:

```bash
python3 yastik.py --kayma 47 --yon "sol omuz" --itiraz "ben buradaydım"
```
